## Featured Projects

### 🤖 Voice-Driven Agentic AI for Form Filling *(M.Sc. Dissertation — IAI, TCG CREST)*
Full-stack agentic system (FastAPI + Playwright + Qwen2.5-72B + Gemini 2.5 Flash + Faster-Whisper) that converts regional voice input into validated form submissions — no GUI required.
- **97% field-completion rate** vs. 45% ASR-only baseline (2.2× uplift)
- **83.69% MD5 cache-hit rate** — minimizing redundant LLM calls in low-connectivity deployments
- Field-validated with 14 participants across West Bengal

### 🔤 Bengali BPE Tokenizer for Low-Resource Indic NLP *(AI Research Intern — IAI, TCG CREST)*
Production-grade Byte Pair Encoding tokenizer built from scratch on 50M tokens of Bengali text (Samanantar / AI4Bharat corpus).
- **1.28× compression** on training set · **1.26×** on held-out test set
- 128-codepoint Bengali base vocabulary (U+0980–U+09FF) · 30 learned merge rules

### ☀️ Solar Cycle 26 Peak Prediction *(Research Intern — IIIT Kalyani)*
LSTM/GRU ensemble with XGBoost meta-learner stacking on 3,316 NASA/WDC-SISLO sunspot observations (1749–2025).
- **XGBoost Ensemble: Test RMSE 17.26, MAE 11.50** — best model
- **~73% improvement** over Linear Regression baseline (RMSE 70.85)
- 132-month multi-output forecast for Solar Cycle 26 peak amplitude
